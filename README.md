## <img src="https://unpkg.com/lucide-static@latest/icons/user.svg" width="20" height="20" /> about

I build APIs, define architectures, and work through infrastructure problems day to day — from database design to production deploys. My current focus sits at the intersection of three things: **solid backend engineering**, **secure LLM integration**, and **architectural decisions that hold up at scale**.

One of the problems I enjoy most is putting AI into real systems without opening a security gap — which is why I've been working on architectures where the LLM never touches the relational database directly, only pre-aggregated, curated data.

Software Engineering graduate from UniCesumar. Professional English (B2). Open to formal backend developer opportunities.
